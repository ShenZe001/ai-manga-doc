# AI漫剧资料库

这是一个基于 Express 的资料库网站，包含公开资料页和独立管理后台。

## 已更新

- 前台改为资料库风格：左侧分类导航、推荐资料、搜索、资料卡片和详情弹窗
- 支持文件下载、PDF/TXT 在线预览、外部工具直达链接
- 手机端改为横向分类导航和单列资料卡片，适配窄屏访问
- 保留原有管理员登录、上传、编辑、隐藏、删除和页面信息设置

## 运行

```bash
npm install
npm start
```

默认端口为 `3000`。生产环境请设置 `ADMIN_PASSWORD` 和 `SESSION_SECRET`，文件存储与对象存储相关变量按原项目配置保留。
